Connected Paediatrics Scoliometer
Upload all seven files to the root of a GitHub repository and enable GitHub Pages (main / root). Open the HTTPS GitHub Pages site in Safari/Chrome, then Add to Home Screen.
Important: sensor support is device/browser-dependent, requires permission on iOS; manual input fallback is included. Clinical accuracy has not been validated. Place the phone face up, with its long edge across the back and use a bridge/support. Zero on a level surface.
